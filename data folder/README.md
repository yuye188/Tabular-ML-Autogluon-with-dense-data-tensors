# Structure
- `dense-dfs:` The subfolder stores all dense datasets that were extracted from the TabArena datasets after the density increment process.
- `dense_dfs_with_transformed_binary_feature:` Subfolder contains datasets processed after the featureization/pivot step.
- `results files:` This subfolder holds the results and relevant information about the density increment process, such as original/final density, original/final number of features, etc.
